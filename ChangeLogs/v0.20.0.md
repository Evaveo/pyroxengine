# v0.20.0 — 2026-08-06

Le HTML et le CSS d'un `UIDocument` deviennent des **assets de projet** référencés (documentUI/
feuilleStyle), sur le modèle des matériaux — plus un thème CSS ne se copie-colle sur chaque écran.

## Ajouté

- Genres d'asset `documentUI` (HTML) et `feuilleStyle` (CSS), créés depuis le panneau Projet
  (« 📄 Nouveau document UI » / « 🎨 Nouvelle feuille de style ») et glissables sur un objet pour
  les affecter à son composant `UIDocument`.
- Un `feuilleStyle` peut être partagé par plusieurs `UIDocument` (thème commun) : le modifier met
  à jour tous les écrans qui le référencent.
- Inspecteur du composant `UIDocument` : deux menus déroulants (Document UI / Feuille de style)
  pour choisir un asset existant, en plus du bouton « ✎ Éditer… ».

## Modifié (0.19.1, rollup)

- La fenêtre d'édition externe (`editeur-externe.js`) s'ouvre désormais en **onglet** plutôt
  qu'en fenêtre popup séparée, et affiche un **aperçu live** (iframe) du HTML/CSS édité.

## Cassant

- `userData.uiDoc` (composant `UIDocument`) référence désormais des assets
  (`documentUIId`/`feuilleStyleIds`) au lieu de stocker `html`/`css` en dur — migration de schéma
  automatique (9 → 10 → 11) pour les projets existants.
- `api.uiDocument(noeud).html`/`.css` passent en **lecture seule** (le contenu vit sur l'asset
  référencé, potentiellement partagé) ; seul `.valeurs` reste lecture/écriture. Aucun script
  livré avec le moteur n'écrivait `.html`/`.css`, donc aucune migration de contenu nécessaire.
