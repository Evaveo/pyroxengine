# v0.182.0 — 2026-09-29

## Ajouté

- **Règle des assets dans les instructions du copilote et du MCP** (`COPILOT_SYSTEM`) : le contenu
  (modèles 3D, images 2D, sons, matériaux, tables, animations, scènes, interface) doit être des
  ASSETS sérialisés, visibles et retouchables dans le panneau Projet ; les scripts ne portent que
  du comportement, un par objet piloté.
- **Contrôle des scripts** (`js/script-asset-lint.js`), appliqué par `attach_script` et
  `replace_script` :
  - **refusé** : fichier encodé en base64, image dessinée sur un canevas, son synthétisé
    (oscillateur, `AudioContext`), plus de 800 lignes ;
  - **signalé** : plus de 300 lignes, géométrie ou matériau three construits en code, table de
    contenu écrite en littéral (vers `create_data`).
- **Six outils du copilote / MCP** pour que le contenu devienne des assets :
  - `create_material` — un asset matériau sans objet porteur ;
  - `import_model` — un modèle glTF / GLB (base64), matériaux et clips compris ;
  - `import_audio` — un vrai fichier son (mp3, wav, ogg, m4a) ;
  - `read_data` — relire une table avant de la réécrire ;
  - `write_animation` — un clip d'animation à clés, éditable dans la timeline ;
  - `read_asset` — relire le contenu sérialisé de n'importe quel asset.

## Contexte

Un jeu façon Age of Empires construit par un agent MCP tenait entièrement dans un seul script de
180 000 caractères : rien n'était visible ni retouchable par le créateur.
