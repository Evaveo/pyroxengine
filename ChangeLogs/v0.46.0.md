# v0.46.0 — 2026-08-10

> Renumeroté de **v0.38.0** à l'intégration du 2026-08-12 : la série animation (v0.33.0 → v0.45.0) occupait déjà ces numéros sur `main`. Règle appliquée à toute la série : **+8 sur la version mineure**. Le contenu n'a pas changé.

Graphe de shader (TSL) : Shader (logique) et Matériau (instance + données), séparés comme
dans Unity, avec un éditeur nodal dans une fenêtre séparée (façon Shader Graph).

## Ajouté

- **Nouveau genre d'asset `grapheShader`** — la LOGIQUE pure d'un shader : un petit graphe
  JSON maison (nœuds + liens) construit récursivement en un vrai
  `THREE.MeshStandardNodeMaterial`/`MeshBasicNodeMaterial` via de vraies fonctions TSL.
  Registre de nœuds : constantes (float/vec3/couleur), `uv`, `temps`, opérateurs
  `math.add/sub/mul/mix/clamp`, `texture`, et des nœuds `param.*` (float/vec3/couleur/texture)
  qui déclarent un point d'entrée nommé — l'équivalent des « Properties » d'un Shader Graph
  Unity. **N'est jamais assigné directement à un objet.**
- **`materiau` (existant) gagne `shaderId` + `valeursParams`** — un matériau peut désormais
  référencer un `grapheShader` et fournir les valeurs qui overrident ses nœuds `param.*`,
  exactement comme un Material Unity référence un Shader. Sans `shaderId`, un matériau se
  comporte exactement comme avant (PBR classique) : zéro migration pour les matériaux
  existants.
- **`+ Graphe de shader`** dans le panneau Assets — crée un graphe par défaut (couleur grise
  unie, cible `lit`). Glisser un `grapheShader` sur la tuile d'un `materiau` lui assigne ce
  shader (glisser sur un objet ne fait rien).
- Persistant en `.p3d` (migrations de schéma v11 → v12 → v13) et en mode dossier-projet
  (`grapheShader` écrit comme fichier `*.graphe-shader.json`), rendu identiquement dans
  l'éditeur et dans un jeu exporté (`js/graphe-shader.js`, fichier réellement partagé embarqué
  par `build.js`).

- **Éditeur nodal** (`js/graphe-shader-editeur.js`) — double-clic sur un asset `grapheShader`
  (ou création via « + Graphe de shader ») ouvre une VRAIE fenêtre séparée (`window.open`, via
  le protocole déjà posé par `editeur-externe.js`), pas une modale interne. Conventions Shader
  Graph d'Unity : pastilles de port à gauche (entrées)/droite (sorties), valeur éditable
  directement sur un port non branché (pas besoin de glisser un nœud Constante séparé), clic
  droit pour ajouter un nœud ou en supprimer un, molette pour naviguer sur le canvas, touche
  Suppr, et un panneau **Blackboard** listant les propriétés exposées (nœuds `param.*`).

## Notes

Les changements d'un graphe se répercutent en direct sur tout objet qui porte, via un
`materiau`, le shader en cours d'édition (même mécanisme que l'édition d'un matériau
classique).
