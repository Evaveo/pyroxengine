# v1.1.0 — 2026-10-09

## Ajouté
- **Exporter → Exécutable Windows (.exe)** : compile le jeu en exécutable sur ce PC, en un clic.
  L'éditeur télécharge le projet bureau et ouvre le lien `pyrox-build://`. Un lanceur installé
  une fois (`Exporter → Installer le lanceur de compilation…`, sans droits administrateur)
  dézippe le projet, lance `npm install` et electron-builder, puis ouvre `dist/`. Il y dépose
  un installeur NSIS et un exe portable. Node.js absent : installation proposée par winget.
  Nouveau module `js/desktop-compiler.js`.
- **Signature de l'exécutable** : nouveau réglage de projet « Certificat de signature »
  (`settings.signingSubject`), qui prend le nom du sujet d'un certificat de signature de code
  du magasin Windows. Il passe dans `build.win.signtoolOptions.certificateSubjectName`. Aucun
  mot de passe ne transite par l'éditeur ni par le projet. Si le certificat réglé est
  introuvable ou expiré, le lanceur refuse de compiler.

## Modifié
- `electron-builder` est demandé en version 26 au moins (`signtoolOptions`).
