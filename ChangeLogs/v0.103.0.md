# v0.103.0 — genre d'asset Profil de post-traitement

## Ajouté

- **Genre d'asset `postProfile`** (`moteur/js/post-profile.js`) : un jeu d'effets de
  post-traitement réutilisable (bloom, vignette, grain, tone mapping, color grading, FXAA),
  chacun avec un flag `overridden` façon Unity Volume — un profil ne définit que ce qu'il
  override. Créable depuis le menu « ＋ Créer » du panneau Projet (`ASSET_CREATORS`), stocké
  sur disque sous `assets/<dossier>/<nom>.postprofile.json` en mode dossier-projet (contenu :
  seulement les effets, comme `.material.json` ne contient que les props), inline dans
  `project.json` en mode projet-fichier. `ensurePostProfileDefaults()` complète un fichier
  partiel ou édité à la main avec les défauts neutres, sans jamais planter sur un profil
  incomplet.
  Premier étage du système de profils post-processing façon Unity Volume — un futur composant
  `PostVolume` (non encore écrit) référencera un profil par id, et `blendPostVolumes()`
  (`moteur/js/post-volume-blend.js`, v0.102.2) mélangera plusieurs volumes actifs.
