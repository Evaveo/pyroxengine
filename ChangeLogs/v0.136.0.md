## Ajouté — les images du projet dans le CSS d'une interface de jeu

- Dans une feuille de style (asset `sheetStyle`), `url("asset:Nom")` désigne la **texture du
  projet** nommée « Nom » : `background: #14335c url("asset:Jardin") center/cover`. Les écritures
  `url('asset:Nom')` et `url(asset:Nom)` sont acceptées.
- Raison : le CSS d'un document vit dans un asset, pas à côté des fichiers ; une URL relative n'y
  désignait rien, et reprendre tel quel l'écran d'un prototype web (fond en image) était
  impossible.
- Une référence inconnue est laissée telle quelle (le navigateur l'ignore sans casser la règle).
