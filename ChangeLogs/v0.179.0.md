# v0.179.0 — le menu Fichier en sous-menus

## Added
- **Sous-menus dans la barre de menus** : une entrée peut porter un `submenu` (liste, ou fonction
  relue à chaque ouverture). Ouverture au survol, au clic (écrans tactiles) et au clavier :
  → ou Entrée pour y entrer, ← pour en ressortir, Échap pour tout fermer. Un sous-menu dont toutes
  les entrées sont masquées disparaît.

## Changed
- **Menu Fichier regroupé** : il comptait vingt-cinq entrées à plat. Désormais :
  - **Nouveau ▸** Projet 3D, 🎮 Projet 2D ;
  - **Ouvrir ▸** Dossier de projet, Fichier de projet (.p3d / .s3d), Projets récents, Hub des projets ;
  - **Enregistrer** (Ctrl+S) ;
  - **Enregistrer sous ▸** Fichier de projet (.p3d), et selon le contexte Dans un dossier,
    Sur le cloud, Copie locale ;
  - Récupérer la sauvegarde automatique ;
  - **Scène ▸** Nouvelle scène, Vider la scène courante ;
  - **Exporter ▸** Build Web jouable, Projet bureau (Electron), Dossier lisible (Git), Données de
    jeu (.json), case « Numéro de version affiché dans le jeu » ;
  - 🌐 Publier en ligne (reste au premier niveau) ;
  - Importer des assets, Bibliothèque de prefabs ;
  - Paramètres du projet, Entrées (Input Map), Plugins.
- Les libellés d'un menu tiennent sur une ligne (la liste s'élargit).
- L'aide cite les nouveaux chemins (Fichier → Exporter → …).
