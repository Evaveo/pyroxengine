# v0.9.0 — 2026-08-04

Refonte de l'éditeur en 10 lots (Lot 0 à Lot 9). Format de projet migré `v2 → v6`
(`moteur/js/serialisation.js:MIGRATIONS`), sans perte pour les projets existants.

## Ajouté

- **Layers de projet** (`projet.layers`) : table `{id, nom, visible, verrouille}`, modale de
  gestion (Affichage → Layers…), `api.parCalque` et l'inspecteur tolèrent id numérique ET nom
  legacy. Masque de layers par caméra (`userData.jeu.camMask`).
- **Vue Game** : rendu scissor depuis la caméra marquée « principale » pendant le mode Lecture,
  sans aides ni post-prod ; le build web exporté choisit la même caméra.
- **Vol libre** (clic droit maintenu + W/A/S/D/Q/E, `e.code`) en plus de l'orbite existante ;
  clic molette reprend le panoramique.
- **Rubber band** : sélection multiple par rectangle sur clic gauche depuis le vide, filtrage
  parent/enfant en une passe (pas d'appel objet-par-objet).
- **Menus contextuels** (clic droit) dans la Hiérarchie (crée un enfant du nœud ciblé) et dans
  la Vue (crée au point visé), construits depuis `TYPES_CREABLES` — les types de plugins y
  apparaissent automatiquement. Barre d'outils réduite à 6 types fréquents (`TYPES_BARRE`), le
  reste reste accessible via le menu Objet et les menus contextuels.
- **Ombres par objet** : `castShadow`/`receiveShadow` éditables et persistés (repli sur `true`).
- **Matériaux** : toggle « non éclairé » (unlit, `MeshStandardMaterial` ↔ `MeshBasicMaterial`) ;
  bouton « Extraire en asset matériau » (promeut un matériau inline en asset partagé sans changer
  l'apparence de l'objet ni toucher aux autres objets).
- **Multi-scripts par objet** (`userData.scripts[]`) : chaque script compile et erre
  indépendamment (une erreur dans un script ne suspend plus les autres) ; interface inspecteur en
  liste (actif/éditer/retirer par script). Déclaration `/* @vars {...} */` en tête d'un script
  pour préremplir/typer `api.props()`.
- **Espace de transform « Vue »** pour le gizmo (Local/Monde/Vue), en plus de Local/Monde ajoutés
  dans la foulée (aucun sélecteur d'espace n'existait avant ce lot) — translate/rotate relatifs à
  la caméra via un proxy `Object3D`, y compris pour une sélection multiple.
- Table `TYPES_CREABLES` unique (barre d'outils, menu Objet, menus contextuels), extensible par
  plugin. Dispatcher d'entrées unique (`enregistrerEntrees`) priorisant sculpture > peinture >
  sélection/caméra. Migration de projet versionnée. Suite de tests (fumée + round-trip de
  sérialisation + lint d'ordre de chargement) et CI GitHub Actions.

## Modifié

- Le glisser-déposer depuis le panneau Projet vers la Hiérarchie accepte tous les genres d'asset
  (prefab, modèle, texture), plus seulement script/matériau/audio.
- Le clic gauche ne déplace plus les objets : seul le gizmo déplace désormais (`R` maintenu,
  code mort, supprimé). Corrige au passage l'incohérence Local/Monde qui venait du glisser manuel,
  et le fait que peindre un prefab ou sculpter un terrain sélectionnait/déplaçait aussi l'objet
  visé.
- `attacherScriptAsset` et l'outil copilote `attacher_script` deviennent additifs (ajoutent un
  script au lieu d'écraser).
- Gizmo/helpers/sol/grille masqués via un layer `THREE.Layers` réservé (31) au lieu de
  `.visible`, que le rendu remettait à `true` en aveugle après chaque passe annexe — corrige au
  passage le bug où un helper masqué par l'utilisateur réapparaissait à chaque image, et le bug
  où les sondes de réflexion cuisaient le sol/la grille dans leurs reflets.

## Corrigé

- `GET /editeur` sans slash final répond désormais une redirection au lieu d'un 404
  (`cloud/serveur/index.js`, `redirect: true` sur le montage statique).
- Création d'objet (bouton, import, prefab depuis la sélection) désactivée en mode Lecture : ces
  objets étaient auparavant silencieusement détruits à l'arrêt (l'instantané restauré datait
  d'avant le lancement).
- Référence à `majMenuPlugins`, fonction inexistante masquée par un garde `typeof` : un type
  d'objet enregistré par un plugin n'apparaissait dans aucune UI.
- Fuite potentielle de focus clavier : les touches tapées dans un champ de saisie ne pilotent
  plus l'Input Map de jeu (`touchesJeu`).
- Raccourcis destructeurs (Suppr, Ctrl+D, 1/2/3, F) désactivés pendant le mode Lecture.
- `redimensionner()` débounce sur `requestAnimationFrame` pendant le glisser d'une poignée de
  split (évitait une tempête de réallocations GPU côté post-prod).

## Cassant

Aucun changement cassant d'API pour les scripts/plugins existants. Le format de projet migre
automatiquement `v2 → v6` au chargement ; les anciens projets restent lisibles sans action de
l'utilisateur. `userData.script` (singulier) est toujours accepté en lecture (convertit
silencieusement en `userData.scripts[0]`) mais n'est plus écrit.
