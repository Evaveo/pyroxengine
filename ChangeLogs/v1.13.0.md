# v1.13.0 — 2026-10-14

## Ajouté

- **Objets « Statique »** (le Static d'Unity) : une case **Statique** dans l'inspecteur, sous le nom,
  décochée par défaut, en multi-sélection, avec un bouton **Appliquer aux enfants**. Elle ne change
  rien dans l'éditeur. Dans le jeu publié, au chargement de chaque scène :
  - les objets statiques dont le matériau final est identique partagent une seule instance de
    matériau (jamais les matériaux de plugin) ;
  - leurs maillages d'un même matériau sont fusionnés en un seul maillage par cellule de 40 unités
    (262 144 sommets au plus par morceau, index 32 bits au-delà de 65 535), en gardant l'uv1
    d'atlas de lightmap de chaque objet ; les objets d'origine restent dans la scène (scripts,
    colliders, déclencheurs, lancer de rayon) ;
  - leurs matrices sont figées : aucun calcul par image ;
  - `api.setPosition`, `api.lookAt`, `api.moveTo` et `api.patrol` sur un objet statique sont
    ignorés, avec un avertissement unique dans la console ; masquer, activer ou détruire un objet
    statique fusionné continue de fonctionner.
- **Cuisson de lightmap** : dès qu'un objet de la scène est Statique, la cuisson de la scène entière
  ne cuit que les objets statiques (un message le dit) ; sans aucun statique, tout est cuit comme
  avant.
- **Copilote** : la commande `transform` accepte `static` et `staticChildren`, et l'inventaire des
  objets indique `static`.
- Page d'aide « Les objets Statiques ».

## Format de projet

- Nouveau champ de nœud `static: true`, écrit seulement quand il est vrai. Absent vaut faux : aucune
  migration, les projets existants s'ouvrent et se publient à l'identique.
