# v0.50.0 — 2026-08-11

> Renumeroté de **v0.42.0** à l'intégration du 2026-08-12 : la série animation (v0.33.0 → v0.45.0) occupait déjà ces numéros sur `main`. Règle appliquée à toute la série : **+8 sur la version mineure**. Le contenu n'a pas changé.

Menu **Fenêtres**, à côté d'Affichage : ouvre directement l'éditeur de code, le graphe de
shader, l'éditeur HTML/CSS ou l'aide, sans passer par un asset du panneau Projet.

## Ajouté

- **Menu Fenêtres** (`ui.js`) : Éditeur de code, Graphe de shader, Éditeur HTML/CSS, Aide.
  Chaque entrée rouvre le dernier fichier édité de ce type durant la session, ou le premier
  disponible dans le projet, ou une fenêtre vide s'il n'y en a aucun.
- **Sélecteur de fichier** dans les fenêtres externes (éditeur de code, graphe de shader,
  éditeur HTML/CSS) : une liste déroulante en haut de la fenêtre permet de changer de fichier
  du projet sans la fermer, plutôt que de devoir revenir au panneau Projet et double-cliquer
  un autre asset.
  - Éditeur de code : liste les assets `script`.
  - Graphe de shader : liste les assets `grapheShader`.
  - Éditeur HTML/CSS : liste les assets `documentUI`. Ouvert ainsi (hors d'un composant
    UIDocument précis), seul le HTML est éditable — l'association à une feuille de style
    vit sur le composant d'un Noeud, pas sur l'asset document lui-même, donc il n'y a pas de
    feuille unique à faire correspondre hors de ce contexte.
