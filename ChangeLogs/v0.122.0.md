# v0.122.0 — template Hub « Troisième personne »

## Ajouté

- **Prefab par défaut « Contrôleur troisième personne »** (`moteur/prefabs-default/tps-controller.prefab.json`,
  enregistré dans `js/prefab-library.js`) — déplacement, saut, caméra d'épaule orbitale à la
  souris avec recul contre le décor. Même patron que le contrôleur FPS existant : le joueur ne
  connaît que le cap du pivot de caméra (`CameraRig`), jamais sa matrice monde.
- **Template Hub « Troisième personne »** (`moteur/js/hub/template-third-person.js`) — la carte
  déjà présente dans le catalogue du Hub (`js/hub/hub-templates.js`) n'affichait que « Bientôt
  disponible » ; elle instancie maintenant le prefab ci-dessus, comme le fait déjà le template
  FPS avec le sien.
- **`jeux/TPS`** — petit jeu de démonstration à la troisième personne construit avec ce nouveau
  prefab : déplacement, caméra d'épaule, cinq cibles à toucher. Le personnage est le modèle
  Mixamo « X Bot » (pack « Male Locomotion Pack », `assets/models/character/`), attaché et
  retargeté sur ses dix clips directement par `build-project.mjs` — la provenance
  (`Model.assetId`, `animExt: [{asset, clip, name}]`) est écrite comme le ferait l'inspecteur de
  modèle, le clip réel du pack (`"mixamo.com"`) et l'unité d'export ayant été vérifiés à la main
  hors navigateur via `THREE.FBXLoader` (`moteur/test/engine-env.mjs`) ; voir
  `jeux/TPS/README.md`.
