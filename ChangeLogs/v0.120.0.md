# v0.120.0 — le copilote pilote les interfaces HTML/CSS

## Ajouté

- **`configure_ui_document`** (`moteur/js/copilot.js`) — attache une interface HTML/CSS
  (composant UIDocument) à un objet, en référençant ou créant les assets `documentUI`/
  `sheetStyle` nécessaires.
- **`write_ui_document` / `write_ui_stylesheet`** — remplacent entièrement le HTML d'un document
  ou le CSS d'une feuille de style attachée à un objet. La description enseigne au modèle la
  syntaxe `data-bind`/`data-bind-class` (`moteur/js/game-ui.js`) par laquelle un élément se lie
  aux valeurs qu'un script écrit via `api.uiDocument(node).set(cle, valeur)`.

Jusqu'ici l'UI de jeu (`component-uidocument.js` + `game-ui.js`) n'était pilotable qu'à la main :
sélecteur de fichier ou fenêtre externe d'édition HTML/CSS.
