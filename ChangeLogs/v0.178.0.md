# v0.178.0 — la revue du 2026-09-29, lots C à G

Corrections de la revue du 2026-09-29 (`docs/REVUE_2026-09-29.md`) : données trompeuses,
divergences du jeu publié, sécurité côté moteur, performance, accessibilité et langue, dette.
MINOR parce qu'un module partagé apparaît (`track-sampling.js`) ; aucun changement de schéma du
format de projet.

## Added
- `js/track-sampling.js` — module **partagé** éditeur / jeu publié : easing, échantillonnage des
  clés et règle « une piste additive a-t-elle une base », en un seul exemplaire (il y en avait
  trois, qui divergeaient).
- Onglets du dock : bouton ×, clic du milieu et Suppr pour fermer ; rôle `tab` pour les lecteurs
  d'écran.
- Menus : navigation au clavier (flèches, Entrée, Échap) ; en-tête nommant l'objet dans le menu
  contextuel.
- Cliquets de dette (`test/cliquets-dette.test.mjs`) : lignes, `.traverse(`, gardes `typeof`,
  `userData.type ===`, mentions « miroir », taille du plus grand cycle d'imports, identifiants
  du glossaire revenus. Chaque mesure a pour plafond sa valeur du jour et ne peut plus que
  baisser.
- Test d'aller-retour réel des assets `sfx` et `musicLoop` (sauvegarde → rechargement → même
  recette, même son).

## Fixed
- **Copilote, `add_event`** : description et énumération alignées sur les actions réellement
  exécutées ; anciens noms traduits, nom inconnu refusé. Les deux moteurs signalent une action
  inconnue au lieu de l'ignorer.
- **Aide** : API de la machine à états, options de `layerAnimation`, `.values` de
  `api.uiDocument` — prompt du copilote compris.
- **Clavier** : Espace, Entrée, Suppr et Retour arrière sur un bouton focalisé n'agissent plus
  sur la scène (Retour arrière supprimait l'objet sélectionné).
- Supprimer un asset en mode dossier se confirme.
- **Bandeau de verrou des projets hébergés** : nom de scène et détenteur échappés (XSS).
- **Jeu publié** :
  - une clé additive sur un os que le clip n'anime pas ne dérive plus ;
  - changer de scène libère matériaux, ciel et cartes d'ombre de la scène quittée (fuite GPU) ;
  - un son absent ou qui refuse de partir est signalé (sources audio construites par une seule
    fonction, `createSourceSound`, pour les deux moteurs).
- **Sécurité** : empreinte de confiance des scripts en SHA-256 (les anciennes empreintes sont
  invalidées, la confiance est redemandée une fois) ; le champ de code multijoueur accepte les
  codes de 6 caractères.
- **Rack sonore** :
  - l'onglet Audio restauré au rechargement n'est plus vide ;
  - le focus clavier survit à la reconstruction du panneau ;
  - « ＋ NOUVEAU » ne crée plus d'homonymes (« Saut 2 », « Saut 3 »…) ;
  - volumes et swing affichent leur valeur.
- Une migration du format de projet qui ne fait pas monter la version **lève** avec un message,
  au lieu de s'arrêter en silence au 20e tour sur un projet à moitié migré.
- `api.audioBus` : un booléen n'est plus accepté comme volume.

## Changed
- **Performance** :
  - BX-16 : une note identique n'est calculée qu'une fois par rendu (boucle de 4 mesures de
    31,6 à 17,4 ms) ;
  - une retouche de recette ne relance plus le regroupement d'instances de toute la scène ;
  - `api.expose` : en-tête de script mis en cache, objets trouvés par un index de noms ;
  - simulation et lecture ne resynchronisent l'inspecteur qu'à 10 Hz ;
  - ouvrir un projet ne reconstruit plus le panneau Projet une fois par asset ;
  - particules : seule la partie vivante des tampons part au GPU ;
  - `fflate` ne part plus dans le jeu publié.
- **Langue** : « Physique » dans la barre du haut ; les mots anglais laissés par les renommages
  dans les textes affichés (« name », « tile », « marker », « folder »…) sont revenus au
  français. Façade du rack en français : MUSIQUE, EFFETS, GÉNÉRAL, MUET, ＋ NOUVEAU, ▶ ÉCOUTER,
  🎲 HASARD, ⤳ MUTER, ▶ LECTURE, ⌫ EFFACER (abréviations d'appareil gardées : VOL, OSC…).
  Titres des composants en français dans l'inspecteur.
- **Accessibilité** : fenêtres modales en `role="dialog"` avec focus piégé ; barre d'état
  annoncée (`aria-live`) ; libellés reliés à leurs champs ; contraste relevé (texte atténué,
  champ invalide) ; cases du séquenceur distinguées par le contour et le remplissage, plus par la
  seule opacité ; grille BX-16 lisible en panneau étroit (deux rangées de 8 pas) ; bouton de
  repli du rack plus grand.

## Removed
- La case « Recuire en lecture » d'une sonde de reflets : elle ne faisait rien depuis le 6 août
  (le jeu recuit toujours toutes ses sondes au lancement). Le champ `auto` reste lu pour les
  anciens projets, et n'a plus d'effet.
- Exports morts : `playerPositionRoot`, `trackOfClipFor`, `SHORTCUTS_NOTE_INPUT`,
  `LOCK_CONSTANTS`, `NAMES_TYPE_TEXTURE`, `sharedGeometryCount`, `resetSharedGeometries`.
- Doublon de `readPath` dans le rack (importé de `chip-synth.js`).
- L'ancien « mode lecture dans l'éditeur » : `modeGame`, `stopGame()` et les 38 branches qui
  testaient un drapeau jamais levé depuis que « ▶ Jouer » ouvre un onglet séparé. La commande
  `set_play_mode` du copilote ne prétend plus arrêter une partie : elle dit que le jeu tourne
  dans un onglet que l'éditeur ne pilote pas et renvoie vers `play_and_measure`.
- 281 gardes `typeof` sur des noms que le fichier importe lui-même (elles ne pouvaient pas
  échouer) ; le reste est plafonné par `test/gardes-typeof.test.mjs`.

## Cloud (hors version du moteur)
- Base de données : migrations numérotées par `PRAGMA user_version`, chacune appliquée une fois
  dans une transaction ; test sur une base ancienne (`bdd-migrations.test.mjs`).
