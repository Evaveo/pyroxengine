# v1.0.0 — 2026-10-09

Première version publique : le moteur prend son nom, PyroxEngine, et sort chez un hébergeur.
À partir d'ici, un changement cassant du format de projet ou de l'API de script exige un MAJOR.

## Ajouté
- **Nouveau nom : PyroxEngine.** Logo PYRO**X** ENGINE (barre de l'éditeur, hub, manuel,
  fenêtre À propos), favicon « X » sur toutes les pages de l'éditeur, du cloud et du portail.
- **Paramètres du projet → Studio.** Le nom du studio signe le jeu exporté en bureau :
  auteur et description du `package.json`, identifiant d'application `com.<studio>.<jeu>`.
  Le moteur sert à plusieurs studios : plus aucun « Evaveo » codé en dur dans les exports.

## Modifié
- Couleur d'accent alignée sur l'orange de la marque (`#ff550a`), éditeur, cloud et portail.
- EvaCore / « Éditeur 3D » renommés PyroxEngine dans les titres, textes et documents.
- Identifiant d'application par défaut : `com.studio.<jeu>` (au lieu de `com.evaveo.<jeu>`).

## Inchangé, volontairement
- Identifiants techniques (clés de stockage `moteur3d-*`, URI MCP `editeur3d://`, addon
  Blender `evaveo_blender_bridge`) : les renommer casserait les données et installations
  existantes sans rien changer à l'écran.
