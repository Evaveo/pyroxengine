Fusion de `staging` (export bureau Electron, publiée là-bas sous le numéro v0.166.0) dans la
branche copilote (v0.166.0 → v0.172.0). Les deux avaient numéroté leur version 0.166.0 en
parallèle : le détail de l'export bureau est dans `v0.166.0.md`, section « Aussi publié… ».

  (build Web .zip, projet bureau Electron, « Publier en ligne »). Elle porte la config multijoueur
  (`data.build.network`). `collectBuildFiles` / `textTrimming` (staging) sont remplacés par
  `assembleBuild` / `trimmingNote`.
- Menu Fichier : « 🌐 Publier en ligne » et « 🖥 Exporter un projet bureau » côte à côte.
