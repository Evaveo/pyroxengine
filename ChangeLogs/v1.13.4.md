# v1.13.4 — 2026-10-15

## Corrigé

- **Un script ne peut plus régler l'éclairage de la scène.** Le moteur refusait déjà un script qui
  crée une lumière ; il refuse maintenant aussi celui qui modifie le ciel, le brouillard ou
  l'environnement (`scene.background`, `scene.fog`, `scene.environment`), ou l'intensité ou la
  couleur des lumières d'ambiance et du soleil. Ces réglages se font dans l'éditeur (fenêtre
  Environnement, composant Lumière) : sinon le jeu lancé ne ressemble pas à la vue Scène et le
  créateur ne peut pas les retoucher.
