## Ajouté — éditeur nodal

- **Sélection multiple**, comme Shader Graph : rectangle tiré dans le vide (par intersection,
  pas par inclusion — un nœud effleuré est pris), `Maj`/`Ctrl`+clic pour composer la
  sélection, `Ctrl+A` pour tout prendre, `Suppr` pour effacer le lot. Un glisser déplace tout
  le groupe du même écart, et cliquer un nœud déjà sélectionné conserve la sélection.

- **Palette portée à 33 nœuds**, aux noms et à l'arborescence d'Unity :
  - *Trigonometry* — Sine, Cosine, Tangent
  - *Procedural / Noise* — Simple Noise, Fractal Noise, **Voronoi**, Cell Noise ; plus
    Checkerboard. Ce sont les fonctions MaterialX (`mx_*`) embarquées par three, sur
    lesquelles Shader Graph s'appuie lui aussi.
  - *Round* — Floor, Ceiling, Round, Sign, Step
  - *Advanced* — Absolute, Negate, Modulo, Normalize, Length
  - *Range* — Minimum, Maximum, Fraction, One Minus, Saturate, Remap
  - *Vector* — Dot Product, Cross Product, Distance
  - *Basic* — Divide, Power, Square Root · *Interpolation* — Smoothstep
  - *Channel* — Combine · *UV* — Tiling And Offset, Rotate
  - *Input* — Position, Normal Vector, Screen Position, Camera Position

- **Panneau « code TSL équivalent »** (bouton `</> Code`), tiroir repliable en bas du graphe :
  le code que le graphe produirait, en lecture seule, régénéré à chaque modification. Utile
  pour comprendre ce qu'on vient de construire, et pour recopier un bout de shader dans un
  script ou un plugin. Les opérateurs y sont **dérivés des mêmes tables que le rendu** : ils
  ne peuvent pas diverger.

## Ajouté — éditeur de code

- **Les scripts JS s'éditent dans une vraie fenêtre**, plus dans une modale. L'ancienne
  offrait une zone de texte nue de 280 px, sans numéros de lignes ni coloration, et masquait
  la scène pendant l'écriture. La nouvelle donne l'écran entier, une **gouttière de numéros de
  lignes**, la **coloration syntaxique**, l'**indentation automatique**, `Tab`/`Maj+Tab` sur
  une sélection, et laisse la vue 3D manipulable à côté. Enregistrement continu : plus de
  bouton « Appliquer » à oublier. Vaut pour les deux éditeurs — asset script du panneau
  Projet et script attaché à un objet.

  `js/editeur-code.js` est un composant réutilisable, **sans dépendance ni build** : embarquer
  CodeMirror ou Monaco pour éditer vingt lignes ne se défend pas dans un dépôt qui tient à
  rester ouvrable en local. Les littéraux d'expression régulière ne sont volontairement pas
  colorés (`/` est ambigu, et une heuristique finit toujours par avaler la moitié d'un fichier
  dans une fausse regex).

## Notes de compatibilité

Aucun changement de format : les graphes et les scripts enregistrés avec 0.48.0 se rouvrent
tels quels. Le schéma de projet reste en version 13.
