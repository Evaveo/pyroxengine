# v1.23.0 — 2026-10-16

## Ajouté

- **Autocomplétion dans l'éditeur de scripts.** En tapant `api.`, une liste propose toute l'API de
  script avec sa signature et une courte explication, filtrée à mesure qu'on tape. Après `api.me.`,
  `api.find('…').`, `api.particles().`, `api.audio().` ou `api.animator().`, elle propose ce que l'objet
  rendu sait faire (et `x`/`y`/`z`… après `.position.`). Une variable affectée d'un de ces appels est
  suivie. Sans point : mots-clés, `start`/`update` et les noms déjà écrits dans le script.
  ↑/↓ pour choisir, Entrée ou Tab pour accepter, Échap pour fermer, Ctrl+Espace pour ouvrir la liste.
