# v1.6.0 — 2026-10-12

## Modifié
- **La mise à l'échelle de l'interface est active par défaut sur TOUS les projets** (mode
  « Tout faire tenir », référence 1280×720, échelle max 1). Sur un écran de 1280×720 ou plus,
  rien ne change ; sur un téléphone ou une petite fenêtre, l'interface entière se réduit pour
  tenir à l'écran au lieu de déborder. Un projet dont l'interface est déjà responsive choisit
  « Aucune (pixels fixes) » dans la section « Mise à l'échelle » du composant Interface (UI).
