# v0.191.0 — Correctifs du projet « Donjon » (pilotage MCP, 2D)

## Corrigé

- **Assets perdus au changement de scène** : l'instantané d'une scène ne contient plus la liste des
  assets ; activer/supprimer une scène ou `fix_prefabs` ne rejoue plus une vieille liste (scripts,
  prefabs, textures créés depuis disparaissaient, prefabs en double).
- **Textures en échec (HTTP 429/5xx)** : réessai avec délai croissant (`Retry-After` respecté). En
  échec définitif, l'asset est gardé (`unloaded`, damier) et la sauvegarde est refusée ; en jeu,
  damier + message, et une tilemap n'attend plus éternellement son image.
- `api.setTile` / `api.tileAt` visent la tilemap demandée (nom, nœud ou parent).
- `api.create(prefab)` : le sprite cloné est recâblé avec ses propres géométrie et matériau ;
  `api.spriteImage` ne plante plus et ne laisse plus de maillage en double.
- Caméra 2D : `configure_camera_2d` est réellement appliqué (cadrage unique `frameOrthoCamera`),
  le frustum reflète la vue rendue, et le suivi se cale sur 1/(ppu×rapport).
- `create_prefab` garde le chiffre final d'un nom explicite ; `slice_sheet` respecte `margin` et
  `spacing`, ppu automatique = largeur de case.
- Nouvelles clés `@vars` propagées aux objets existants (sans écraser).
- Une exception dans `update` n'arrête plus le script (comme Unity) : erreur relayée une fois par
  seconde avec son compte, bandeau en jeu.
- La console reçoit de nouveau les messages du jeu après un rechargement de l'éditeur ; `api.log`
  remonte ; messages multilignes conservés.
- Lint : une petite boucle bornée (≤ 8) dans `start` est acceptée ; `audit_project` reconnaît
  `var X = exports`.
- Un groupe créé sans position naît en (0,0,0).
- `play_and_measure` : relevés calés sur le temps du jeu (plus de relevé à t=0).
- Bascule d'autorisation de l'IA : un seul consentement partagé, le pont MCP se reconnecte seul.

## Ajouté

- `import_image {replace:true}` (garde l'id), paramètre `ppu` sur `import_image`/`slice_sheet`.
- `delete_asset` / `move_asset` par `id`.
- `add_palette_tiles`, `set_script_vars`, `script_api_reference`.
- `set_parent {keepWorld:false}`.
- Auto-tuilage 8 voisins (47 tuiles, `blob:true`).
- `play_and_measure {keys, objects}`.
- `manage_scenes reorder` / `set_start` ; champ additif `settings.startScene`.
- Le gestionnaire `api.on` d'un clic UI (`data-event`) reçoit les valeurs `data-bind` ; documenté.
- Avertissement : le tri de profondeur 2D ne s'applique qu'à l'intérieur d'un calque.
