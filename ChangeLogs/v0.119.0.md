# v0.119.0 — le copilote pilote les sondes de réflexion

## Ajouté

- **`create_object`** accepte désormais le type `probe` (`moteur/js/copilot.js`) — le type
  existait déjà côté moteur (`TYPES_CREATABLE`, `js/objects.js`) mais n'était pas dans l'énumération
  exposée au copilote.
- **`configure_reflection_probe`** — règle une sonde de réflexion (composant Reflection) :
  rayon d'influence, résolution du cubemap, intensité, cuisson automatique au lancement du mode
  lecture, et projection boîte (`box`/`boxSize`/`boxOffset`) pour garder le reflet accroché aux
  murs d'une pièce plutôt que de sembler venir de l'infini.
- **`bake_reflection_probes`** — cuit (ou recuit) le cubemap d'une ou plusieurs sondes sans
  attendre le lancement du mode lecture, en s'appuyant sur `bakeProbe()` (`moteur/js/probes.js`).
  Ces réglages restaient uniquement accessibles à la main dans l'inspecteur.
