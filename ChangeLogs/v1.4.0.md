# v1.4.0 — 2026-10-12

## Ajouté
- **MCP cloud : plusieurs projets ouverts en même temps.** Chaque onglet de l'éditeur peut servir
  ses propres URL MCP : case « Cet onglet » sur chaque URL du panneau MCP (mode « Via le cloud »).
  Un appel fait avec une URL arrive dans l'onglet qui la sert. Une URL par projet, et deux IA (ou
  deux serveurs MCP déclarés dans le même client) pilotent deux projets sans se gêner. Le choix
  est propre à l'onglet et survit à un rechargement de la page.

## Modifié
- Un nouvel onglet connecté au relais ne remplace plus l'ancien que s'ils servent les mêmes URL
  (ou si aucun des deux n'en sert : comportement d'avant). Message `bind` ajouté au protocole
  éditeur → relais, champ `tokenIds` dans le `hello`.
