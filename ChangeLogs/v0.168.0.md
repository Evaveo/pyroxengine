# v0.168.0 — une IA qui enregistre et range son travail

Un agent branché par MCP a construit un niveau complet… jamais enregistré : un rechargement l'a
effacé. Il le posait aussi en vrac (objets « Cube 12 » à la racine, scripts à plat).

## Added
- Outil copilote/MCP **`save_project`** : enregistre le projet là où il vit (cloud ou dossier).
- Outil copilote/MCP **`move_asset`** : range un asset dans un dossier du panneau Projet.
- Règles d'**organisation du projet** dans les instructions du copilote (et donc du MCP) :
  sauvegarde à chaque étape, hiérarchie en groupes parents, noms explicites, assets rangés par
  type puis par usage, intention consignée dans le document de conception.
- `read_console` rend aussi les `console.error` / `console.warn` du navigateur — éditeur et jeu
  en mode Lecture (le runtime les relaie à l'éditeur depuis son iframe).

## Fixed (v0.167.2)
- `play_and_measure` échouait toujours (« Cannot access 'window' before initialization ») :
  une variable locale masquait la globale `window`.
