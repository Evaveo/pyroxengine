# v0.184.0 — 2026-09-29

Une IA qui pilote l'éditeur par MCP apprend enfin les règles du moteur. Avant cette version, elle ne
recevait RIEN : les règles partaient dans le `hello` de l'éditeur, après le `initialize` du client.
Elle construisait donc les jeux d'un bloc, dans un seul script, invisible et impossible à retoucher
pour le créateur. C'est un moteur de jeu : tout ce que l'IA fabrique doit rester manipulable.

## Ajouté

- **Savoir-faire de l'IA en une source** (`js/ai-guidelines.js`, pur) : règles, guides et recettes,
  partagés par le copilote intégré (`COPILOT_SYSTEM`) et le pont MCP. Nouvelle règle **MÉTHODE** :
  plan (`write_design`) → assets → scènes peuplées d'objets réels → un script court par comportement,
  attaché et rangé → vérification → `save_project` ; pas de « GameManager » qui fait tout, réglages
  en `@vars` visibles dans l'inspecteur.
- **Pont MCP** (`outils/mcp-bridge/bridge.mjs`) :
  - instructions du moteur dans `initialize`, **éditeur connecté ou non** ;
  - **ressources** : guides `editeur3d://guide/{regles, methode, scripts, jeu-2d, niveau-3d,
    materiaux, sons}`, état du projet `editeur3d://projet/{scene, assets, audit, conception}`,
    usage `editeur3d://pont/usage` ;
  - **prompts** : `nouveau_jeu`, `peupler_scene`, `ajouter_comportement`, `audit_projet`,
    `decouper_script` ;
  - **compteur d'usage** par outil (appels, échecs, enchaînements `a → b`), cumulé entre sessions
    (`MCP_BRIDGE_USAGE_FILE`, `off` pour le couper) — pour savoir quels outils composés ajouter ;
  - **retours d'erreur** : outil inconnu → noms proches et domaine à charger ; script refusé →
    guide à lire ; `listChanged` étendu aux ressources.
- **Relais cloud** (`cloud/back/mcp/`) : mêmes ressources et prompts, reçus de l'éditeur dans
  `hello.knowledge` (le cloud n'importe rien du moteur) ; les règles du moteur priment sur les
  consignes du copilote dans `initialize`.
- **`audit_project`** (`js/project-audit.js`, pur) : audit de STRUCTURE — script qui porte l'essentiel
  du code, objets créés en boucle dans `start`, scène vide pour beaucoup de code, nombres en dur sans
  `@vars`, objets à la racine ou au nom générique, assets en vrac, script non attaché.
- **`attach_script`** : `script` (nom de l'asset) et `folder` (défaut `Scripts`) — le script est
  créé nommé et rangé en un appel ; sans `code`, `script` attache un asset EXISTANT (réutilisation,
  pas de copie). Le retour liste les réglages `@vars` exposés.

## Modifié

- `COPILOT_SYSTEM` est bâti depuis `ai-guidelines.js` : le texte n'existe plus qu'à un endroit.
- L'ancien serveur `mcp/protocole-mcp.mjs` renvoie lui aussi les instructions du moteur.
