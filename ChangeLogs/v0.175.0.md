# v0.175.0 — les bus de mixage : Musique, Effets sonores, Volume général

Premier lot du Rack sonore (spec `docs/superpowers/specs/2026-09-28-sound-rack-v1-design.md`,
lot A). Jusqu'ici chaque son partait droit vers les haut-parleurs : impossible de baisser la
musique face aux bruitages, ni d'offrir un curseur « Musique » au joueur.

## Added
- `js/audio-bus.js` — module **partagé** éditeur / aperçu / jeu publié : trois bus (`master`,
  `music`, `sfx`), `music` et `sfx` passant par `master`. Sans DOM ni THREE ; seul `sound.gain`
  est rebranché, le panoramique 3D d'une source positionnelle reste intact.
- Source audio : champ **Bus** (`userData.audio.bus`, `sfx` | `music`). Absent → `sfx`.
- Paramètres du projet → **Mixage audio** : un volume par bus (0 à 2), stocké dans
  `project.settings.audioBuses` et embarqué dans le build.
- API de script : `api.audioBus(nom)` → `.volume(v?)`, `.mute(on?)`, `.muted()`, identique dans
  les deux moteurs (`makeAudioBusApi`). La sourdine repart à zéro à chaque partie.
- `api.playSound(nom, volume?, bus?)` : troisième argument facultatif, `sfx` par défaut.
- Bouton **Audio** dans la barre du haut (à côté de Physics) : ouvre le **Rack sonore**, panneau
  dockable (`js/sound-rack.js`, id `sound-rack`). Premier module, **MX-3** : une console de mixage
  façon matériel années 80 — une tranche par bus avec fader, afficheur 7 segments et MUTE.
  Les volumes vont dans `project.settings.audioBuses` (même donnée que Paramètres du projet →
  Mixage audio) ; la sourdine est un état d'écoute, non enregistré. Les modules SX-1 et BX-16 y
  sont annoncés. Jetons de couleur `--rack-*` dans `css/tokens.css`.
- Copilote : `configure_audio_mix` (lit ou règle les volumes des bus) ; `configure_audio` accepte
  `bus`.

## Changed
- Les notes du synthé (`api.playNote` / `playNotes`) sortent sur le bus `sfx` au lieu de
  `ctx.destination` : elles obéissent désormais au volume général. `makeSynthApi` prend un
  cinquième argument facultatif `getDestination`.
- L'aperçu d'un asset (panneau Projet) ne passe volontairement par aucun bus.

## Fixed
- `configure_audio` écrivait `maxDistance` et `slope`, champs que ni le moteur ni l'inspecteur ne
  lisent (`distanceMax`, `rolloff`) : les deux réglages étaient acceptés, rapportés comme faits, et
  sans effet sur le son.
- Aide : `api.audio()` documentait `.jouer()`, alias supprimé ; c'est `.play()`.

## Migration
- Aucune étape de format. Un projet sans `audioBuses` reçoit `{master:1, music:1, sfx:1}` et ses
  sources sortent sur `sfx` : le son est **identique** à avant. Passer les musiques sur « Musique »
  reste à faire à la main.
