# v0.25.0 — 2026-08-08

L'aide devient une page, et un test l'empêche de mentir.

## Ajouté

- **`moteur/aide.html`** — l'aide est une **page**, ouverte dans un onglet à part et
  réutilisé. **20 pages, 15 termes de glossaire**, sommaire permanent, recherche,
  liens d'ancre. La modale interdisait le seul usage qui compte : lire en
  travaillant, l'éditeur à côté.
- **Trois tableaux de référence engendrés depuis le code**, pas transcrits :
  toutes les propriétés de matériau (depuis `PROPS_MATERIAU`), toutes les commandes
  du copilote (depuis `COMMANDES`), toute l'API de script et ses alias anglais.
  Transcrits, ils périmeraient ; engendrés, ils ne le peuvent pas.
- **`moteur/test/aide.test.mjs`** — onze gardes qui confrontent l'aide au code :
  ancres, commandes dans les deux sens, noms d'API, raccourcis, liens internes,
  fichiers cités, et jusqu'aux **absences que l'aide affirme**.
- Sept sujets qui n'avaient aucune aide : scripts et objet `api`, physique et
  colliders, particules, terrain, interface de jeu, multijoueur, profileur.

## Modifié

- Les entrées de menu « Raccourcis clavier » et « API de scripts » mènent aux
  pages. `modalRaccourcis` et `modalApiScripts` sont **supprimées** : devenues
  inatteignables, et toutes deux périmées — la seconde ignorait la physique,
  l'état de jeu, les évènements et le multijoueur.
- `js/aide.js` ne fait plus qu'ouvrir la page.

## Corrigé

- **Trois pages de l'aide mentaient**, et c'est ce qui justifiait l'exercice :
  « ▶ Jouer lance le jeu dans la vue, Échap restaure la scène » était faux sur les
  trois points depuis que le mode Lecture s'ouvre dans un onglet ; « sans sonde, un
  objet n'a aucun reflet » était faux depuis que le ciel sert de sonde par défaut ;
  la modale des raccourcis décrivait un mode Lecture qui n'existe plus.

## Notes

**Ce que la rédaction a refusé d'écrire, faute de preuve** : le plafond de joueurs
par salon (il vit dans `cloud/`, destiné à se séparer de `moteur/`) ; les valeurs
par défaut des matériaux (absentes de `PROPS_MATERIAU`) ; comment régler une
distance de disparition — `userData.detail.distance` est honorée et sérialisée,
mais **aucun inspecteur ne l'écrit**.

**Un écart relevé au passage** : deux documents annoncent une gravité de −9,81, le
code applique **−9,82**. L'aide dit ce que fait le code.

**Trois des onze gardes échouaient au premier lancement**, et pour la même raison :
un tableau né dans un contexte `vm` porte le prototype de CE contexte, donc
`deepEqual(liste, [])` échoue même quand les deux sont vides — en affichant « [] »
des deux côtés. Les valeurs sont désormais rapatriées à la sortie du bac à sable.
Le dépôt s'y était déjà fait prendre.

**Vérifications** : lint 58 fichiers, **152/152**. Les gardes anti-invention sont
éprouvées par **mutation** — commande inventée, nom d'API inventé, fichier cité
inexistant, ancre périmée : chacune fait rougir un test. Et la page a été ouverte
dans un navigateur, ce que la rédaction n'avait pas pu faire.
