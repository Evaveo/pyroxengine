# v1.8.5 — 2026-10-12

## Corrigé

- WebGPU : un matériau qui utilise plus de 16 textures (matériau standard + ombres + lightmap +
  sondes) ne s'affichait plus (« The number of sampled textures (19) … exceeds the maximum
  per-stage limit (16) »). Le moteur demande maintenant au GPU les limites qu'il supporte
  réellement, dans l'éditeur comme dans le jeu publié.
- Import depuis Blender : la console n'est plus inondée de « THREE.Texture: Unable to serialize
  Texture » à chaque étape d'historique ; les textures vivantes ne sont plus envoyées à la copie
  de l'historique.
- Réimporter le même modèle ne déclenche plus la fausse alerte « Deux fichiers importés
  s'appellent… ».
