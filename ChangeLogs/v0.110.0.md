# v0.110.0 — le Project Hub

Un nouvel écran, `moteur/hub.html`, s'ouvre avant l'éditeur : liste des projets ouverts
précédemment, création d'un projet (choix d'un dossier réel sur le disque, via le sélecteur
natif) et sélection d'un template de départ. Entièrement local — aucune dépendance au serveur
cloud, comme tout `moteur/`.

Aucun format de projet n'est touché ; le Hub réutilise le manifeste `project.json` existant et
le mécanisme de projets récents déjà en place (`moteur/js/recents.js`).

## Ajouté

- **`moteur/hub.html`** — le nouvel écran d'accueil local. Liste les projets récents
  (`listProjectsRecents()`, déjà utilisé par « Projets récents… » dans le menu Fichier) avec un
  rendu graphique plutôt qu'un `prompt()`, et propose la création d'un projet avec un template.
- **`moteur/js/hub/hub-templates.js`** — le catalogue de templates, et son seul point
  d'extension : `HubTemplates.register({id, label, description, thumbnail})` déclare un
  template visible dans le Hub ; `HubTemplates.attachApply(id, fn)` lui attache un contenu réel,
  depuis un fichier que seul l'éditeur charge (`createSceneNode`/`addComponent` n'existent pas
  dans le Hub). Un template déclaré sans comportement attaché s'affiche normalement, marqué
  « Bientôt disponible » — c'est le cas de **Troisième personne** et **WebXR / VR**, posés dès
  maintenant pour que leur arrivée n'ait à toucher que leur propre fichier `template-*.js`.
- **Template « FPS — déplacement »** (`moteur/js/hub/template-fps.js`) — un personnage
  `Player > Camera`, sans arme : regard souris (cap sur le joueur, tangage sur la caméra) et
  `api.moveCharacter` (`moteur/js/game-character.js`), le contrôleur déjà partagé par l'éditeur
  et le jeu publié. Un point de départ neutre, pas une démo — voir l'audit de
  `jeux/NeonBreach/src/player-fps.js` qui a établi que son contrôleur de déplacement était déjà
  entièrement découplé de son arme.
- **Template « Plateforme 2D »** (`moteur/js/hub/template-platformer-2d.js`) — branche le
  préréglage déjà existant du menu « 🎮 Nouveau projet 2D… » (`newProject2d()`,
  `moteur/js/serialization.js`) sur le Hub, sans le dupliquer.
- **`autoOpenPendingHubProject()`** (`moteur/js/project.js`) — reçoit la main du Hub au
  démarrage de l'éditeur (`moteur/js/startup.js`) : rouvre le dossier créé, applique le template
  choisi s'il en a un, l'enregistre sur le disque.
- **« Retour au Hub des projets… »** — nouvelle entrée du menu Fichier de l'éditeur.
