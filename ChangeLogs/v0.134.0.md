# v0.134.0

Ce fichier reprend aussi les PATCH accumulés depuis la v0.133.0 (0.133.1 et 0.133.2), qui n'ont
pas de fichier propre.

## Ajouté — viser sous le pointeur

- `api.pointerRay()` : le rayon monde `{origin, direction}` qui passe par la souris ou le doigt,
  depuis la caméra du jeu (perspective ou orthographique) — l'équivalent de ScreenPointToRay.
- `api.pick(filter?, distance?)` : l'objet sous le pointeur, par `api.raycast` le long de ce rayon.
  Même filtre que `api.raycast` (tag, calque).

## Corrigé

- **Un tap sans glisser visait l'endroit du tap précédent.** La position du pointeur n'était
  mise à jour que sur `pointermove`, qu'un doigt qui tape n'émet pas. Elle l'est maintenant aussi
  sur `pointerdown`, dans l'éditeur et dans le jeu publié.
- (0.133.1) Les tables de données (`data`) s'écrivent en vrai fichier `.data.json` en mode
  dossier-projet, au lieu d'être rangées en ligne dans `project.json`. Un projet d'avant reste lu.
- (0.133.2) La surcouche tactile passe sous l'interface du jeu : la zone de glisser mangeait les
  clics des boutons du HUD.
