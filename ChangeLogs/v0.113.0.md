# v0.113.0 — le copilote pilote l'Animator 3D

## Ajouté

- **`configurer_animator`** (`moteur/js/copilot.js`) — attache une machine à états (Animator,
  `moteur/js/animator.js`) à un objet 3D — modèle importé ou groupe qui en contient un — en créant
  l'asset animator s'il n'en a pas encore.
- **`lire_machine_animator` / `ecrire_machine_animator`** (`moteur/js/copilot.js`) — lisent et
  remplacent entièrement le JSON de la machine (paramètres, états, transitions, mélanges 1D),
  avec les clips disponibles sur la cible et les assets d'animation du projet pour écrire des
  états qui citent des noms réels. Les problèmes (état sans sortie, clip inconnu, paramètre non
  déclaré…) sont signalés après écriture, comme `analyser_scene`, plutôt que refusés en bloc.
  Seule `configurer_anim_sprite` (2D, planches de sprites) existait jusqu'ici ; l'Animator 3D
  restait uniquement pilotable à la main dans l'inspecteur.
