# v0.171.0 — un jeu multijoueur publié ailleurs que sur le cloud

## Added
- Le build Web inscrit l'adresse du relais multijoueur (`data.build.network`) : l'origine du cloud
  qui sert l'éditeur, ou `project.networkServer` s'il est réglé. `api.network` s'en sert par défaut.
  Avant, un jeu publié sur itch.io cherchait le relais à sa propre origine (404).
- Relais (`cloud/`) : les routes `/api/reseau/salon` et `/api/reseau/etat` sont ouvertes en CORS,
  sans credentials. La création de salon depuis un autre site n'envoie plus de cookies.

## À savoir
- Le relais doit être PUBLIC et en HTTPS pour des joueurs sur itch.io : une page https ne peut pas
  ouvrir de `ws://`, et `localhost` n'est joignable que depuis ta machine.

Les correctifs v0.170.1 et v0.170.2 sont décrits dans `v0.170.0.md`.
